# buncli

`buncli` is installed on this machine. Its instructions ship inside the binary, so they always match the installed version.

Before you first use it in a session, run:

```bash
buncli skills get core
```

Then use `buncli schema` for the full command reference, and `buncli skills` to list guides for individual commands. Always pass `--json` and `--non-interactive`.
